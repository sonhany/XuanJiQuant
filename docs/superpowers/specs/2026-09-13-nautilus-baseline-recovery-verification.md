## 证据

| 验证项 | 证据与结论 |
|---|---|
| 准入与账户 | T+1 不因新决策 ID 解锁；停牌、价格带、单位、新鲜度和超现金拒绝；现金与可卖量预留 |
| 部分成交 | 原生 IOC 限制到可信一档，共享可见容量；实际部分成交，剩余取消，预留释放 |
| 重复请求 | 同内容同 ID 只保存一条结果；改内容同 ID 拒绝；重复订单意图不再提交 |
| 并发写入 | 同进程及竞争子进程均被单写者锁拒绝；外部强杀持锁者后能够重新获取锁 |
| 强制退出 | 输入提交后、输出提交后两个断点，分别覆盖 os._exit(77) 和父进程 kill；重启重放与未中断结果一致 |
| 完整性 | 输入/输出被改动拒绝；状态查询不把损坏结果报告为完成；无关数据库拒绝且数据库文件不改变 |
| 命令行 | run/recover/status 实际子进程调用，相同结果；身份冲突返回非零退出码 |

测试驱动修复了三个问题：持久化后调用方仍可修改执行输入；状态查询未核验输出完整性；未拒绝已有无关数据库。分别通过复制已验证输入、统一读取核验、建表前识别数据库结构修复，并保留回归测试。
