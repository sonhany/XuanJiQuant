# XuanJiQuant 稳定性收敛与职责简化设计

## 1. 目标

本阶段不新增产品功能，不推倒重写。唯一目标是把现有系统收敛为“确定性量化内核 + 受约束 Agent 控制面 + 只读展示层”，修复业务决策、系统健康、执行资格和恢复状态互相污染的问题，使模拟交易闭环可解释、可验证、可回放。

项目继续保持 `paper-only`。不得接入真实资金，不得绕过 verifier、执行会话、幂等键、硬风控或审计账本，不得降低硬风险阈值。

## 2. 单一职责边界

### 2.1 确定性量化内核

数据、因子、策略、组合约束、订单数量、A 股交易规则、硬风控、订单状态机、成交、持仓、现金和对账都由确定性代码负责。LLM 输出不能覆盖这些事实。

### 2.2 Agent 控制面

Agent 只负责检查证据、触发既定任务、在已通过研究门禁的候选中形成计划、解释决策、调用 verifier、申请受控模拟执行、跟踪工具回执并触发恢复。Agent 不直接写订单、成交、持仓或现金事实，不改变硬风控，不自动晋升研究产物。

### 2.3 展示层

页面只投影权威事实，不自行推导权限。主界面只展示四个权威域：`data_status`、`agent_decision`、`safety_gate`、`paper_execution`。调度模式、恢复次数、租约、会话和 fencing token 进入诊断详情。

## 3. 决策语义

`trade_policy` 只有三种业务语义：

- `normal`：允许计划包含增加或降低目标仓位，但仍须逐单经过硬风控。
- `reduce_only`：只允许降低现有风险；不得出现买入，不得提高任一持仓目标权重，不得提高组合总敞口。
- `no_new_position`：不允许新增仓位；允许无交易计划，或仅包含确定性的卖出/持有动作。无可执行调仓是合法业务终态，不是系统故障。

组合合同验证必须按策略分别验证，不能再把 `trade_policy == normal` 当成唯一合法合同。合同验证通过只说明计划结构与策略语义一致，不等于订单获批。

## 4. 系统健康与业务许可分离

恢复健康回答“系统能否可靠完成一次已知业务结果并留下完整证据”，交易许可回答“本轮是否允许新增、仅减仓或不交易”。两者不得互相替代。

以下结果属于已知业务终态，不得触发系统级恢复：

- 合法的 `reduce_only` 计划；
- 合法的 `no_new_position` 或无交易计划；
- 硬风控或市场规则明确拒单且回执完整；
- 部分成交后剩余数量明确取消或登记为待执行，且账本完成对账。

以下情况必须失败关闭并进入恢复或维护：

- 模型/规划器响应无法解析且没有可验证终态；
- 计划结构损坏或策略语义冲突；
- 工具副作用未知；
- 订单、成交、持仓或现金无法对账；
- 执行会话、权限、幂等绑定或 verifier 证据缺失；
- 紧急停止或硬风控服务不可验证。

恢复检查中的 `verifier_passed` 表示本轮形成了可验证的已知终态，而不是“本轮必须允许买入”。`hard_risk_clear` 表示没有系统级硬风险故障或未知风险，不得根据 `reduce_only/no_new_position` 字面值直接判失败。

## 5. 展示规则

页面必须使用中文说明首要阻挡原因，内部代码只可在诊断详情中显示。`verifier_not_passed` 显示为“本轮计划尚未通过验证”，不得截断为英文残片。

恢复态统一显示“Agent 自治恢复中”，并展示中文原因和下次预计验证时间；不得显示“Agent 未启用”。正常的只减仓、不新增、无交易和明确拒单必须分别展示，不能统一成系统故障。

## 6. 黄金闭环验收

本阶段必须覆盖并验证以下六类闭环：

1. 正常买入并完全成交；
2. 正常卖出并完全成交；
3. `reduce_only` 只产生减仓动作并形成合法终态；
4. 普通拒单完成回执与审计，不触发系统恢复；
5. 部分成交后剩余取消或待执行，订单与工具回执均为明确终态；
6. 回执未知时失败关闭，完成对账后恢复，恢复后首个模拟交易使用清洁基线。

每条链必须可由同一 `decision_id/run_id` 追踪证据、计划、verifier、风险、订单、成交、持仓、现金和审计事实。

## 7. 非目标

本阶段不拆分全部超大模块，不引入新数据库，不重写前后端，不新增数据源、因子、策略、页面或实盘接口。模块拆分只在当前修复需要明确职责边界时进行最小提取。

## 8. 完成判定

完成必须同时满足：策略感知合同测试通过；恢复健康不再误读业务许可；未知副作用仍失败关闭；工作台中文状态契约通过；六类黄金闭环相关测试通过；Node 契约、TypeScript、Vite 构建和相关 Python 回归通过；README、交接文档和全景图规则同步。任何一项没有证据都不能宣称完成。
